# NETWORKWALKS-RAVAHA-B084-WK3-PASSWORD-CRACKING

# 1. Introduction

In this weeks task, i cracked multiple passwords for multiple chrome pdf files using john the ripper CLI/Johnny GUI as well as NETWORKWALKS password cracker by using turning those pdfs into hash values and then decrypting them using John the ripper and NETWORKWALKS password cracker.


# 2. Tools Used

1. John the Ripper CLI
2. Johnny GUI
3. PDF to hash extractor
4. NETWORKWALKS password cracker


# 3. Procedure

1. Download JTR and Johnny from the original site and extract them
2. After extracting, run Johnny and place john.exe from JTR folder into Johnny
3. Then take the locked PDFs and extract their hash codes using PDF hash extractor
4. Insert those hash codes into JTR or NW password cracker and gain the password
5. Enter the password into the locked PDF and gain access
